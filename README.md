# 📊 Interactive E-Commerce Sales Dashboard

Dashboard interaktif berbasis web untuk menganalisis data transaksi penjualan *e-commerce*, efisiensi kanal distribusi, dan status pengiriman logistik secara *real-time*.

## 🚀 Fitur Utama
- **KPI Summary:** Total Omzet, Total Transaksi, dan Total Unit Terjual.
- **Interactive Filtering:** Filter interaktif berdasarkan Kanal Penjualan dan Status Pengiriman.
- **Visual Analytics:** Grafik batang horizontal per produk & Donut Chart status pengiriman.

## 🛠️ Tech Stack
- **Python** (Pandas)
- **Streamlit** (Web Framework)
- **Plotly** (Interactive Data Visualization)
